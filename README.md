# EpicSweep Assets

Public CDN repo for EpicSweep brand assets. Served via jsDelivr.

## URL Pattern

```
https://cdn.jsdelivr.net/gh/FranciscoCrespo1/epicsweep-assets@main/PATH
```

## Assets

| Asset | Path | URL |
|---|---|---|
| Logo (avatar) | `brand/logos/main/avatar.png` | [link](https://cdn.jsdelivr.net/gh/FranciscoCrespo1/epicsweep-assets@main/brand/logos/main/avatar.png) |
| Coin GIF | `brand/coins/gif/coin-animated.gif` | [link](https://cdn.jsdelivr.net/gh/FranciscoCrespo1/epicsweep-assets@main/brand/coins/gif/coin-animated.gif) |
| GC Coin (static) | `brand/coins/png/GC_coin_front.png` | [link](https://cdn.jsdelivr.net/gh/FranciscoCrespo1/epicsweep-assets@main/brand/coins/png/GC_coin_front.png) |
| Mr. Sweep (jackpot) | `brand/mascots/mr-sweep/mr-sweep-jackpot.png` | [link](https://cdn.jsdelivr.net/gh/FranciscoCrespo1/epicsweep-assets@main/brand/mascots/mr-sweep/mr-sweep-jackpot.png) |

## Adding new assets

1. Add file to the correct `brand/` subfolder
2. `git add . && git commit -m "add asset-name" && git push`
3. jsDelivr URL is live immediately
